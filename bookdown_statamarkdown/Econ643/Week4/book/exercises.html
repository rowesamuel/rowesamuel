2.1.1 Explanatory and Outcomes

Steps

  1. Use the file gss2006_chapter6.dta
  2. Our variables of focus will be sex and premars
  3. Let’s answer the question: Do men and women have different views on premarital sex?
  4. Which variable is the explanatory/independent variable?
  5. Which variable is the outcome/dependent variable?
  6. Run a tabulate command. We want to include conditional percentage \(P(Opinion|Men)\) and \(P(Opinion | Women)\)
  7. Calculate a \(\chi^2\) statistics.
  8. Do you find a statistically significant difference?
  9. Calculate a Cramer’s V.
  10. What do you find about the relationship?
  11. Interpret the conditional percentage.

2.1.2 Categorical and Quantitative Variables

Steps

  1. Use the file gss2006_chapter6.dta
