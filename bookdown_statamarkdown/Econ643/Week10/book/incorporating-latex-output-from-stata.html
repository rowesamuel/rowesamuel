Chapter 3 Incorporating LaTex output from Stata

3.1 Table commands

Table command is provides a basis to create customized tables for descriptive statistics. However, we can use the collect command after the table command to export our results into various documents of our choice.

3.1.3 Customize the format

We can customize the formats with sformat to add string characters and nformat to format the numerics.

table () (sex union) () if prerelg==1, statistic(frequency) statistic(percent) statistic(mean earnings) statistic(sd earnings) statistic(median earnings) nototals nformat(%6.2f  mean sd median) sformat("$%s" mean sd median) sformat("%s%%" percent)
