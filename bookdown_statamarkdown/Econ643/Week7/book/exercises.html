Chapter 3 Exercises

3.1 Randomization

We will create a random sample from a random number generator.

Step

  1. Create a blank file with 1000 observations
  2. Generate an id variable based on the row number.
  3. Set a seed to 91925
  4. Create a variable called wages with a random number generator with \(\mu=1500\) and \(\sigma=500\)
  5. Summarize wages. What is the mean, minimum, and maximum?
  6. Generate a new random number called random_num.
  7. Sort ascending using random_um and create a new ranking variable.
  8. Create a new variable called treatment.
  9. Those 500 and below are set at 0 and those at 501 to 1000 are set at 1
  10. Label the treatment variable 0 “Control” 1 “Treatment”.
  11. Use a \(t\)-test to test the null hypothesis \(\mu_{(control)}-\mu_{(treatment)}=0\)
  12. What do you conclude?

3.2 National Longitudinal Survey of Youth

Do Latino families have more have more children than other ethnic groups? Load the file called “nlsy97_chapter7.dta” to answer the question.

Step:

  1. First summarize hh18_97 which is the number of children under 18
  2. Next, tabulate ethnic97 which is a binary for Latino/Hispanic
  3. Test the null hypothesis \(H_{0}: \mu_{(Latino)}-\mu_{(Non-Latino)}=0\)
  4. What do you conclude?

3.3 General Social Survey

Are women more likely to say that abortion is okay under any circumstances than men? Load the file called “gss2002_chapter7.dta”.

Steps

  1. First, tabulate abany
  2. Next, tabulate sex
  3. Then do a cross-tabulation on abany and sex
  4. Use the prtest command on abany and sex. What happened?
  5. We need to recode our variable into a binary.
  6. Generate a new variable based off of abany and label No 0 and Yes 1.
  7. Finally, test the null hypothesis: \(p_{(women)}-p_{(men)}-1\)
  8. What do you conclude?
